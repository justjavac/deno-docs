通常人类不会直接使用这个子命令。'deno lsp' 可以为 IDE
提供跳转到定义支持和自动代码格式化功能。

:::

启动 Deno
语言服务器。语言服务器被编辑器用来提供智能提示、代码格式化等功能。了解更多关于
[与 Deno LSP 集成](/runtime/reference/lsp_integration/) 的信息。

## 描述

'deno lsp' 子命令为代码编辑器和 IDE 提供了一种通过语言服务器协议与 Deno
交互的方式。

了解更多关于
[如何将编辑器和 IDE 连接到 `deno lsp`](https://deno.land/manual@v1.42.4/getting_started/setup_your_environment#editors-and-ides)
的信息。
