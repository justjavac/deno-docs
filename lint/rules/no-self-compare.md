禁止在比较的两边完全相同的情况下进行比较。

将变量或值与自身进行比较通常是一个错误，可能是打字错误或重构错误。这会让读者感到困惑，并可能引入运行时错误。

**无效示例：**

```typescript
if (x === x) {
}
if ("x" === "x") {
}
if (a.b === a.b) {
}
if (a["b"] === a["b"]) {
}
```

**有效示例：**

```typescript
if (x === y) {
}
if ("x" === "y") {
}
if (a.b === a.c) {
}
if (a["b"] === a["c"]) {
}
```
